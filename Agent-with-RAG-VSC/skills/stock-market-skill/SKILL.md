# Stock Market Skill

## Name
Stock Search and Market Signal

## Description
This skill identifies the highest percentage gainers or largest decliners from a stock market data source. It is useful when the user asks for recent market movers or sector performance.

## Trigger Queries
- Show me the biggest gainers today.
- Which stocks fell the most?
- Find the most promising trending stocks.

## Tool
- `stock_search.get_top_market_moves`

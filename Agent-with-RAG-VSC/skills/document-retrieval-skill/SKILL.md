# Document Retrieval Skill

## Name
Document Chunk Retrieval

## Description
This skill retrieves the list of relevant text chunks from the document vector database. It is designed for keyword queries and concept search across ingested source documents.

## Trigger Queries
- Find relevant passages about marketing strategy.
- Search the company financial report.
- Pull context about agent architecture and retrieval.

## Tool
- `document_search.query_document_chunks`

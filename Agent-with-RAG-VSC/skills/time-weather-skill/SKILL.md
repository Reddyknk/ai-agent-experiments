# Time and Weather Skill

## Name
Time and Weather Lookup

## Description
This skill fetches the current time and weather forecast for a city using a public Open-Meteo API. It is useful when users ask for the local time, current weather, or a short forecast in a specific city.

## Trigger Queries
- What is the weather in Tokyo?
- What time is it in Paris?
- Will it rain in Berlin tomorrow?

## Tool
- `time_weather_skil` / `fetch_city_weather`
